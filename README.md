# 実行方法

```
npm install
npx playwright install chromium
```

```
npm start -- --date 20260602 --retry 200
```

```
npm start -- --date 20260602 --retry 200 --point
```

```
npm start -- --date 20260602 --retry 200 --debug
```

# option

+ `--date yyyymmdd`
  + yyyymmddで予約したい日付を設定
  + デフォルト翌日
+ `--today`
  + 当日の日付を指定する(`--date`より優先)
+ `--destination R004`
  + 予約する行き先を指定。R003, R004のいずれか
    + R003: 京王八王子・高尾山口・高幡不動→新宿方面
    + R004: 橋本・京王多摩センター→新宿方面 (デフォルト)
+ `--retry 1`
  + リトライ回数を指定
  + デフォルト20(3秒*20回=1分)
+ `--target 07:10`
  + 予約する便を発車時刻(HH:MM)で指定。
  + 画面上の表示順には依存しない(実行時刻によるずれなし)
  + 例: `05:45`, `06:18`, `07:10`, `08:14`, `08:26`, `08:50`, `09:37`
  + デフォルト`07:10`
  + 立席は対象外(指定席のみ予約)
+ `--point`
  + ポイント購入モードで起動(ポイントで支払う)
+ `--debug`
  + デバッグモードで起動(購入を実行せずに終了)


# Slack通知

実行結果を `~/workspace/shellscripts/bin/slack/notify_webhook.sh`(cross_listと共通)でSlackに通知します。

| 結果 | 通知内容 |
|---|---|
| 予約完了 | 日付・行き先・便・支払方法、確保した便の表示内容、何回目で取れたか、所要時間 |
| debug完了 | 上と同じ(購入はしていない旨を表示) |
| 空席なし | 条件と、リトライ回数分試しても取れなかった旨 |
| エラー | 条件とエラーメッセージ |

+ 通知スクリプトは環境変数 `NOTIFY_SCRIPT` で差し替え可能
+ スクリプトが無い・通知に失敗した場合も予約処理自体は止めない
+ 座席番号は自動割当のため通知に含まれない(購入完了メールで確認)
